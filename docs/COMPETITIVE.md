# Competitive landscape

## Builders: Muse vs PlutusShield

[Meta Muse](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/) is a general personal AI agent. It is not a Cardano or Midnight insurance product. PlutusShield is a specialized DeFi insurance stack; Muse is not a product competitor here.

## Product: Aegis vs PlutusShield

[Aegis](https://aegis.fluxpointstudios.com/) (Flux Point Studios) is live parametric insurance on Cardano — pool-funded cover against objective triggers (price barriers, liquidations, stale oracles), with Aiken validators and an SDK for partner protocols.

| Dimension | Aegis (today) | PlutusShield (target) |
|---|---|---|
| Chain | Cardano | Cardano + Midnight |
| Cover model | Parametric | Parametric **and** evidence-based exploit cover |
| Privacy | Public policy / pool surface | Private policy terms, evidence, underwriter books via Midnight ZK + selective disclosure |
| Partner embed | Aegis SDK | Planned SDK after core products |
| Status | Mainnet parametric protocol | Scaffold / design (this repo) |

## How we win

1. **Privacy where it matters** — size, exposure, and claims evidence stay private by default.
2. **Exploit cover** — not only parametric events.
3. **Dual-chain honesty** — Cardano for money; Midnight for secrets; never pretend one chain does both well.
4. **Buyer UX** — marketing site + app that explains cover clearly, not only a protocol console.

We respect Aegis as the current Cardano parametric bar. PlutusShield’s job is to clear a higher bar on privacy and cover breadth — not to copy a landing page.
